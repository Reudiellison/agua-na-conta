# 💧 Água na Conta

> Sistema de educação financeira e hídrica para famílias brasileiras.

**[🔗 Acesse o site ao vivo](https://seu-usuario.github.io/agua-na-conta/)**

---

## 🎯 Sobre o projeto

O **Água na Conta** é um projeto social que transforma os dados da sua conta de água em informações simples, alertas de desperdício e dicas práticas de economia — conectando tecnologia, educação e vulnerabilidade econômica.

### Funcionalidades

| Feature | Descrição |
|---|---|
| 📋 Análise da conta | Interpreta valor, consumo e nº de moradores |
| 📊 Variação mensal | Calcula % de aumento/redução vs mês anterior |
| 📈 Gráfico histórico | Visualiza tendência de consumo dos últimos meses |
| 👥 Per capita | Compara com benchmark OMS (110–200 L/dia) |
| ⚠️ Alertas inteligentes | Detecta suspeita de vazamento e desperdício |
| 💡 Dicas personalizadas | 5 sugestões adaptadas ao perfil de consumo |
| 🧮 Simulador de economia | "Se eu reduzir 20%, quanto economizo?" |
| 🖨️ Relatório imprimível | Layout otimizado para impressão |

## 🛠️ Tecnologias

- **HTML5** semântico e acessível
- **CSS3** com variáveis, grid, flexbox e animações
- **JavaScript** vanilla (sem frameworks)
- **[Chart.js 4](https://www.chartjs.org/)** para gráficos

## 🚀 Como usar localmente

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/agua-na-conta.git

# Abra o index.html no navegador
start agua-na-conta/index.html
```

Não precisa de servidor — funciona abrindo o arquivo diretamente!

Este projeto foi desenvolvido como iniciativa de projeto social no curso de **Análise e Desenvolvimento de Sistemas (ADS)**, com foco em:

- 💙 Acesso à informação para famílias de baixa renda
- 💧 Consciência sobre o uso sustentável da água
- 📱 Tecnologia acessível (funciona sem instalação, no celular)
